# gs-portal

Modernes, responsives Gesundheitsportal für Berlin mit:

- zentralen Notfallkontakten (112, 116117, Krisendienst)
- filterbarer Übersicht von Gesundheitsangeboten nach Bezirk, Kategorie und Stichwort
- optimierter Mobile- und Desktop-Darstellung
- Vorsorge- und Präventionstipps

## Lokal starten

```bash
python3 -m http.server 8000
```

Dann im Browser öffnen: <http://localhost:8000>
